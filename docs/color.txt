5. PRIMARY COLOR USAGE
============================================================

FLAME SCARLET — #CD202C

Use for:

    Primary CTA
    Add button
    Save button
    Confirm button
    Active tab
    Active navigation item
    Selected filter
    Progress bar
    Progress ring
    Important action
    Focus indicator
    Important academic highlight


DO NOT use Flame Scarlet for:

    Large continuous text areas
    Entire card backgrounds
    Full-screen backgrounds
    Every icon
    Every status


The color should communicate:

    "This matters."
    "This is active."
    "Take action here."

============================================================
22. ACCESSIBILITY RULE
============================================================

Color must never be the only way to communicate information.

Example:

    WRONG:

    Red = urgent


    BETTER:

    [!] DPCO Assignment
    Due Today


The color reinforces the meaning; the text/icon provides the
meaning.


============================================================
23. COLOR OPACITY GUIDELINES
============================================================

For overlays and subtle accents, use opacity rather than
introducing unnecessary new colors.

Suggested:

    Primary tint:
        #CD202C at 10–15%

    Primary active surface:
        #CD202C at 15–20%

    White overlay:
        #FFFFFF at 5–10%

    Black overlay:
        #000000 at 20–50%


Opacity values may be adjusted during implementation based on
actual device rendering and accessibility testing.


============================================================
24. DESIGN TOKEN RULE
============================================================

Components MUST reference semantic tokens.

DO NOT write:

    backgroundColor: "#CD202C"


inside every component.

Prefer:

    backgroundColor:
        colors.primary


Therefore the palette can be changed globally without rewriting
the component system.

============================================================
26. BRAND COLOR RATIO
============================================================

Recommended visual balance:

    Near Black:
        ~65–75%

    Surface / Elevated Surfaces:
        ~15–25%

    White / Warm Ivory:
        ~5–10%

    Flame Scarlet:
        ~3–8%

    Semantic colors:
        Only when required


The application should feel predominantly dark and controlled.

Flame Scarlet should create emphasis rather than visual noise.
